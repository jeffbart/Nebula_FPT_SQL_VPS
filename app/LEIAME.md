# Código da aplicação

Esta pasta contém o runtime Python do Nebula FTP SQL VPS.

A documentação principal fica um nível acima:

- `..\README.md`;
- `..\docs\INSTALLATION.md`;
- `..\docs\ARCHITECTURE.md`;
- `..\docs\SECURITY.md`.

O inicializador também fica na raiz da implantação:

```text
..\iniciar_nebulaftp_vps.bat
```

Não coloque `.env`, certificados privados, sessões Telegram, staging ou logs
dentro desta pasta.
